- Clean, modern Python 3.10+ implementation.
- Typed signatures and robust error handling.
- Comprehensive unit test coverage.

## Installation & Usage

```bash
git clone https://github.com/rajveersinh-is-dev/k-regular-partition-log-concavity.git

python "experiments/benchmark_performance.py" --help
```
